## Reading guide

Each image receives 3 cues (C1–C3). Each cue is assessed against the 7 audit dimensions from N0_MANUAL_CUE_AUDIT_PROTOCOL.md §3. Preliminary decision: **PASS / REVISE / REJECT**.

Annotation types used:
- `[OBSERVED WORDING]` — the cue text as drafted
- `[MANUAL AUDIT JUDGMENT]` — qualitative assessment
- `[REVISION RECOMMENDATION]` — proposed correction (no replacement wording specified here)
