## 1. Why this sweep matters

The repository-only audit understated the amount of existing visual material. The ChatGPT Library contains a much richer legacy bank than the six current Wave 1 pairs.

The important consequence is not that V2 already has a validated item bank. It does not.

The consequence is:

> V2 does not need to start visual ideation from zero.

The legacy bank already contains many scene families that can be rebuilt into independent exemplars of the new Decision Driver trade-offs.

## 3. Most important rediscovery: Pair P0 already contained V2-like trade-offs

The old Pair P0 scoring model should not migrate, but two Pair P0 concepts are unusually relevant to the new Decision Driver architecture.

### P0-002 — closed gate vs open gate

Historical cue language included:

```text
CLOSED GATE
"Čia saugiau"
"Mane stabdo"
"Kas yra už jų?"

OPEN GATE
"Noriu eiti"
"Per daug atvira"
"Dar nežinau, ar žengti"
```

Under the old architecture these responses were hand-mapped into AW/CS/CR vectors.

Under V2 the scene is better understood as a candidate **motivational collision shell**:

```text
Opportunity / Exploration
        vs
Protection / Safety
```

This does not mean that the old image is already valid for that collision. It means the conceptual scene deserves migration into a new V2 family.

### P0-003 — closed box vs open box

Historical cue language included:

```text
CLOSED
"Noriu žinoti, kas viduje"
"Gali palaukti"
"Geriau neatidaryti"

OPEN
"Pagaliau aišku"
"Nežinomybė buvo įdomesnė"
"Kažko trūksta"
```

This is a strong conceptual seed for:

```text
Certainty / knowing
        vs
Exploration / mystery
```

Again: the old item is not scoring-valid. Opening a box changes visible information and object reveal by definition, so low-level and semantic confounds are substantial. Preserve the trade-off concept; redesign the exemplars.

### P0-001 — formal shoes vs casual shoes

Historical language mixed:

```text
prepared / dependable / demanding
        vs
freedom / unstructured / moving
```

Potential V2 themes include Autonomy, Certainty/Preparedness and Influence/Status, but clothing style, class/formality, aesthetics, work context and cultural norms are inseparable.

**Decision:** archive as conceptual history, not a V2 scoring seed.

## 7. Asset-bank architecture for V2

The existing visual bank should not be copied directly into the product directory.

Create four conceptual states:

```text
LEGACY_SOURCE
    historical generated/uploaded image

SCENE_SHELL
    useful context, no scoring meaning

V2_CANDIDATE
    reconstructed pair tied to a predeclared driver collision

VALIDATED_ITEM
    only after blind semantic + confound + choice + cross-exemplar validation
```

A Library image may jump from `LEGACY_SOURCE` to `SCENE_SHELL` after curator review.

It must **not** jump directly to `VALIDATED_ITEM` because it looks psychologically meaningful.

---

## 8. Reuse rule

Do not ask:

> “What does this old image measure?”

Ask:

> “Can this image serve as one controlled realization of a driver conflict whose construct definition existed before this image was selected?”

That rule prevents the old circularity from returning under new driver names.

---

## 9. Immediate practical implication

Before generating new V2 images, create a candidate board from the Library and historical repo assets.

Recommended first board:

```text
COLLISION 1: Autonomy ↔ Certainty
- current partition/open seed
- 3–5 legacy scene shells

COLLISION 2: Certainty ↔ Exploration
- partial reveal seed
- box concept
- envelope / hidden-sculpture / blank-canvas shells

COLLISION 3: Opportunity ↔ Protection
- gate concept
- elevator / doorway / lock shells
```

Then select **scene diversity**, not the prettiest images.

The objective is multiple independent realizations of the same driver collision, so that one shared visual preference cannot explain the result.

## 10. Updated verdict

The image situation is better than the repository-only audit suggested.

We do **not** have only six narrow gray-object pairs.

We already have a substantial legacy concept bank containing thresholds, gates, doors, hidden information, packages, paths, abstract geometry, social spacing and ordinary-object scenes.

Most are not ready to score. But several are highly reusable as V2 scene shells.

The biggest rediscovery is that the old Pair P0 gate and box concepts were already circling the new V2 questions:

```text
What pulls me toward opportunity despite protection?
What pulls me toward certainty despite curiosity?
```

The old system tried to convert those reactions into AW/CS/CR vectors too early.

V2 should instead preserve the **trade-off itself**, replicate it across independent scenes, and estimate which motive repeatedly wins.
