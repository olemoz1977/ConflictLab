# Post-Test Interview

Conducted after Session 3. Questions must be open, neutral, and free of leading suggestions.

This should feel like a short conversation, not a 20-question survey.

## Opening

"I am interested in how you understood and experienced the tool. There are no correct answers."

## Core questions (required — ask all 10)

1. What did you think the tool was asking you to do?
2. How did you decide between the images?
3. Did the suggested wordings help you describe your reaction, or did they influence it?
4. Did seeing your chosen words together add anything?
5. Was there a moment when the tool seemed to say more than it could actually know?
6. What did you think the radar meant? *(skip if the radar was not shown — see note below)*
7. Did the radar add value, confusion, or neither? *(skip if the radar was not shown)*
8. Would you use this again without being asked?
9. What was the most confusing or least useful part?
10. In one sentence, what do you think ConflictLab currently does?

**Note on the radar:** if the radar did not appear during the test (eligibility criteria not yet met), skip questions 6 and 7 entirely. This is not a participant failure — it is an expected outcome depending on session count and data. Mark it as "not shown" on the Results Summary, not as "no."

## Optional probes

Ask these only if a core answer was unclear, or if the topic comes up naturally. They are not required for every participant.

- What did you think the image choices represented, if anything?
- Was there a moment when the tool helped you notice something you had not named before?
- How did you understand the difference between not seeing a connection yet and preferring not to name it?
- Did the session history help you notice anything across sessions?
- What would make you return?
- What would make you stop using it?
- What should be removed?
- What is missing?
- Did any text feel like a judgment, diagnosis, or personality label?

## Follow-up rules

**Allowed neutral follow-ups:**
- "Can you tell me more?"
- "What made you think that?"
- "Where did you notice that?"
- "What did you expect to happen next?"

**Forbidden follow-ups:**
- "Did it reveal your need for safety?"
- "Did you notice a pattern?"
- "Do you think the radar was accurate?"
- "Was this your System 1 response?"
