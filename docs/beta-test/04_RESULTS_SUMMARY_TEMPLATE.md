## J. Decision framework

Choose one primary direction after the test.

### Continue with current Pair P0
Only if:
- Most participants understood the flow
- The literal reflection provided value
- No significant interpretive harm occurred
- At least some participants want to return

### Revise reflection flow
If:
- Cues were often felt as leading
- Participants did not understand the connection question
- History text was confusing

### Remove or demote radar
If:
- Most participants did not understand it
- It was mistakenly perceived as a personality profile
- It added no value without the author explaining it

### Stop Pair P0 and return to main ConflictLab
If:
- The pair-choice mechanism itself provides no reflective value
- Participants chose mostly on aesthetics
- The system required constant tester explanation to function
