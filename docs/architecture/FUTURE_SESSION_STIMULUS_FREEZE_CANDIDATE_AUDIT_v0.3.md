## 3. Provenance state

The repository now proves the exact source bytes without relying on filenames alone.

For every asset, the corrected manifest records:

```text
repository path
+
Git content-addressed blob SHA
+
source commit
```

This is sufficient to detect any accidental replacement, re-encoding, crop or file substitution under the same logical pair identity.

A separate SHA-256 may still be generated by the existing asset-freeze tooling when materializing a future-session stimulus-set artifact. That is normalization, not recovery of missing binaries.
