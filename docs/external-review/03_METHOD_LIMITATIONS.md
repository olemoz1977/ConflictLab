# 03 — Method Limitations

This document states current limitations directly, without a defensive tone.

## Stimuli

- The image stimuli are not normed for valence, arousal, complexity, or low-level visual features (luminance, contrast, spatial frequency, etc.)
- There is no control for the possibility that a choice reflects aesthetic preference, familiarity, or incidental visual salience rather than any psychologically meaningful dimension
- The current stimulus set (three image pairs) is explicitly experimental and was not designed with the controls required for psychological interpretation of choice

## Meaning of a choice

- A choice between two images may be driven by aesthetics, contrast, familiarity, fatigue, or chance
- A faster choice is not inherently "more authentic" than a slower one — this is an untested hypothesis, not a finding
- No manipulation check exists to rule out these alternative explanations

## Axes (AW/CS/CR)

- These are an internal, project-defined experimental model, not an external validated scale
- No factor analysis, convergent validity, or discriminant validity study has been performed
- "Confidence" values attached to cue-to-vector mappings are internal weights assigned during content design, not statistical or diagnostic confidence intervals

## Radar and vectors

- The radar is an experimental visualization of an unvalidated vector average
- It is not a final result and is explicitly labeled in-product as not a personality assessment
- The visual scale used (a nonlinear power transform for small-value visibility) is a rendering choice, not a measurement transform — exact numeric values are always shown separately as the authoritative figures

## Reflection

- Text a person writes belongs to the person; the system never rewords, summarizes, or interprets it
- An unstated reflection ("I do not see it yet" / "I prefer not to name it") is not evidence that the person noticed nothing — these are two explicitly distinct, non-deficit response options
- The system draws no conclusion from silence

## LLM use

- Pair P0 does not use any LLM or external AI API for interpreting user input, at any stage
- In the main ConflictLab product (v0.7), any future LLM-generated output carries epistemic risks, including apophenia (perceiving patterns in noise) — any LLM-derived text must be explicitly bounded and never presented as a factual conclusion about the person

## Validation

- No convergent, discriminant, or predictive validity evidence exists for any Pair P0 measure
- No normative data exists
- Sample sizes to date are those of internal development testing (a small number of sessions by the product's own developer), not a study sample
- There is no basis for using this system in clinical or organizational selection contexts
