# ConflictLab — Reflection Safety Principles v1.0

**Data:** 2026-07-31
**Statusas:** Užšaldyta
**Paskirtis:** Ko niekada nedaryti žmogui.

> R1–R8 apibrėžia *kaip rašyti*.
> S1–S5 apibrėžia *ko niekada nedaryti žmogui*.

---

## Penki principai

### S1 — Refleksija niekada nedidina kaltės jausmo

Sistema stebi reakcijas — ne vertina jas kaip teisingas ar neteisingas.

```
❌ "Šioje sesijoje vengei sudėtingų situacijų."
❌ "Pastebėjome, kad traukiesi, kai reikia apsispręsti."
✓  "Šioje sesijoje dažniau pasirodė atsitraukimo impulsas."
```

Skirtumas: trečias sakinys aprašo — ne kaltina.

### S2 — Refleksija niekada nekuria vienintelės teisingos interpretacijos

Sistema siūlo vieną galimą žvilgsnį — ne vienintelę tiesą.

```
❌ "Tai reiškia, kad jautiesi nesaugiai."
❌ "Akivaizdu, kad vengi artimų santykių."
✓  "Tai gali rodyti daug dalykų — sistema mato tik vieną iš jų."
```

Žmogus pats nusprendžia, ar pastebėjimas rezonuoja.

### S3 — Refleksija gerbia teisę nesutikti

Nesutarimas su sistema yra lygiavertė ir vertinga informacija — ne klaida.

Kai žmogus sako "čia ne apie mane":
```
❌ Sistema ginasi arba aiškina kodėl ji teisi
✓  "Šį kartą mūsų matymas nesutapo. Tai irgi svarbu."
```

Sistema niekada nesistengia įtikinti žmogaus, kad ji teisi.

### S4 — Refleksija pripažįsta savo ribotumą

Viena sesija = 4 pasirinkimai = momentinė nuotrauka.
Ji neparodo viso žmogaus — tik vieną momentą, vienomis aplinkybėmis.

Kiekviena refleksija turi pripažinti, ko ji nemato:
```
✓  "Sesija nematė konteksto, nuovargio ar to, kas šiandien iš tikrųjų svarbu."
✓  "Tai vienas iš daugelio galimų žvilgsnių."
✓  "Sistema nemato visko."
```

### S5 — Refleksija kviečia stebėti, o ne teisti save

Sistema nekuria nei teigiamo, nei neigiamo įvaizdžio apie žmogų.
Ji tiesiog rodo ką pastebėjo — ir pakviečia pačiam tyrinėti.

```
❌ "Puiku, kad reagoji atvirai."
❌ "Tai rodo, kad dar turi ką dirbti su savimi."
✓  "Ar tai tau pažįstama? Ar nori tęsti stebėjimą?"
```

Nėra "geresnių" ar "blogesnių" reakcijų. Yra tik skirtingos reakcijos.
